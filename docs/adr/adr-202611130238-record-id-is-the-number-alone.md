# A record's id is its four-digit number alone

- Source: the user, by questionnaire, 2026-11-13; ratified by questionnaire the same day.
- Scope: the Atlas data file, the Atlas page, and every file named after a record.

An id is the record's four-digit number, kept as text, such as 0154. It carries no part of the address, so it does not change when an entry is re-filed. Every id in use before this ruling, such as DΔ-L-0154, is kept in the record as a former id and goes on resolving to the record, so existing links keep working. Picture files are named by the number.
