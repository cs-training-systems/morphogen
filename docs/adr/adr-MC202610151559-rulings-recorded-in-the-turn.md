# A ruling is recorded as soon as it is made, in the very same turn, timestamped from a checked clock. 

- Source: the user, 2026-10-15; the text ratified by questionnaire and placed in CLAUDE.md, "Tidiness and governance".
- Scope: any ruling and any record in this project.

The CLAUDE.md text this record promotes:

> DO NOT let a ruling wait until session end to be recorded: propose its record in the turn the ruling is made, and when the user is present make its ratification the next question they see; when the run is unattended, record it as the project prescribes. DO NOT take a timestamp for any record from memory or from a shell that may ignore the time zone: take it from a clock checked in the project's stated zone.
