# Commit, tag, push and release proposals state the version in so many words
- Source: the user, 2026-10-15; the text ratified by questionnaire and placed in CLAUDE.md, "Versioning, commits and releases".
- Scope: any commit, tag, push, release or other external action Claude proposes in this project.
The CLAUDE.md text this record promotes:
> DO NOT commit, tag, push, release or take any other external action before it has been proposed and the user has said yes to that proposal; DO NOT treat approval to change files as approval to commit them. DO NOT make such a proposal without stating, in so many words: the version the repository carries now; every file that declares it; whether this action changes that version; if it does, the number it would become, the increment and the reason, and the changelog entry; if it does not, the words "no bump". DO NOT omit from the proposal the name of any file that will be tracked, any change, or any discernible consequence, including what becomes public.
