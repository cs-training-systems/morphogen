# A test harness is checked before its verdict is stated or believed

- Source: the user, 2026-10-15, in the user's own words; placed in CLAUDE.md, "Quality gates".
- Scope: any check, test or verification Claude runs in this project.

The CLAUDE.md text this record promotes:

> DO NOT state or believe a test harness's verdict before the harness itself has been checked: when a check fails, first confirm the input the check actually received (a shell can mangle a payload the tool would have handled).
