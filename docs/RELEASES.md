## Earlier tags

Before 0.6.0 the project was numbered 1.0.0 … 2.0.0-beta.3; those six releases were renumbered 0.1.0 … 0.6.0 and then the history was restarted at 0.1.0. The old tags (`v1.0.0`, `v1.0.1`, `v1.0.2`, `v2.0.0-beta.1`, `v2.0.0-beta.2`, `v2.0.0-beta.3`) no longer exist on GitHub. cs-web-folio still pins `v2.0.0-beta.2` by its resolved commit `7ba1c60`; see KNOWN-ISSUES.
