Morphogen — media capture

Renders every preset's still on the graphics processor through the engine itself (the automata need thousands of lattice steps at full resolution, which the processor path cannot do in reasonable time), then offers each as a PNG. Open this page from a local server at the repository root (for example python -m http.server 8090, then /tools/capture.html), press Render, save each file into docs/media/ under the name shown. Nothing here is fetched from the network.
