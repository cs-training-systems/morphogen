    How an address works

    Every entry answers four questions, always in this order.

    Example

    1. 1 · Law architecture

      What kind of rule is it?

    2. 2 · Substrate

      What does the rule act on?

    3. 3 · Mechanism family

      Which mechanism carries it out?

      The formalism that implements that rule on that carrier. It depends on the first two answers.

    4. 4 · Subtype

      Which group within the family?

      A grouping for browsing. It is not a further axis.

    • Mathematics first. The first two answers are the mathematics of the entry and always come first. The mechanism comes third.
    • The rule, not the look. An entry is filed by its rule as written, never by how its picture looks.

        About the Atlas

        How entries are filed

        The Atlas is a faceted classification: each entry carries one value for each facet, always cited in the same order. An entry is one precisely specified generator or mathematical object, not an informal model name. Each generator has its own space of parameter settings, its morphospace. The Atlas is the index of those spaces, which is where its name comes from.

        • The rule, not the solver. A numerical method that approximates an equation is not the equation. A drawing method is not the object it draws.
        • The model, not one output. A rule and one particular pattern it produces are separate entries, linked to each other.
        • The state, not the display. An equation for a continuous field stays a continuous-field entry when a computer evaluates it on a grid, unless the grid rule itself is the model.
        • Chance only when it is in the rule. A rule without chance that starts from a random state is still deterministic.
        • One address per entry. A named model with several valid formulations gets one entry for each formulation.
        • The kind of entry is an attribute. Whether an entry is a model, an equation, a static object or a family of models is recorded beside the address, not inside it.
        • Not a complete list. No finite list of mechanism families can be proved complete. The Atlas is a curated map with room for new mechanisms.
